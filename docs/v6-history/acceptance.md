| 去重与归因 | 去重包含代码、场景/在制、环境版本、偏好、执行额度与恢复检查点；重复回执不执行或记功两次。工具试跑纳入策略和资源分配统计。 |
| 断点恢复 | 模型回合、工具回执、算法状态/控制器与最好完整排程分别保存；工具可以通过 `resume_trial_id` 接着原分支推进。 |
| 文档 | 更新运行目录、架构、测试证据；历史说明放入 `docs/v5-history/`。格式化 TS，但未声称已拆完大型编排文件。 |

## 7. 本轮结论与仍有的限制

- 可交付的快速首解入口得到改善；单次44节点引擎回放也减少了开销。
- 原硬约束及完整校验保留，不能将缓存或剪枝视为放宽规则。
- 真实模型修正仍是主要未解决的效果问题：需要改进生成算法质量和失败后的搜索决策，不能靠延长运行就声称有效。
- Memory与qwen3.7-plus摘要/更新沿用既有能力，本轮没有证明跨订单经验泛化收益。
- 候选域仍是关键事件加显式延迟，不是全排程穷举；没有证明最优或全局无解。
- 首解入口与真实模型各一对短测不足以判断广泛稳定性；交付的是这次观测到的改善和可复查证据。
