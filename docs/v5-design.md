# v5 实现边界与验收口径

## 固定环境与可修改算法

`reference/` 为原始工艺、炉、压机和车辆模型，哈希必须与旧版一致。
`guard-manifest.json` 另外保护 physical_model、verification、production_state、scoring。
模型不获得服务器 Shell、任意文件写入、网络访问或验证器修改权限。
它可以通过算法工具提交新的完整 `construct()` Python 模块。模块可定义辅助函数、循环、候选范围、延迟候选、分支和回退；不只是给定候选打分。

代码在受限 Python 语法/API 环境内运行，状态以句柄传递。`advance` 只接受对应状态签发的候选，不能伪造入炉温度、保温上限或设备容量。模型的字典/列表是副本；完整方案必须再经独立物理审计和完整 CP 模型逐约束验算。
这不是任意 Python 的通用安全沙箱。未开放的系统调用和语言功能不在本项目的模型代码能力中。

## 三个构造入口

|入口|用途|边界|
|---|---|---|
|legacy|保留原有快速构造与基线|旧批次限制保留，便于对照|
|extended|保留旧模型排序程序|原队首、前四候选等限制保留，只作兼容入口|
|calendar|新算法开发环境|跨待投订单候选、车辆/压机/炉时间表、空隙插入、完整构造代码|

新算法不受旧 `backtrack_budget<=32` 和 `wip_limit` 隐含限制；其分支和回退由源代码决定。计算仍有显式 wall/opcode/工具调用额度，结束时是未知或未完成，不是无解。

## 时间与约束

时钟基于观测时刻，不因预约未来任务而跳过之前的空隙。全部新任务必须不早于当前实际状态，过去和已开始的任务不可移动。

按整条工艺路线从交期倒推最晚保温/锻打时刻，计算包括每火最低有效保温、锻打、去压机及离开压机的运输。静态边界与冻结 CP 模型变量域逐项对照。已承诺的入炉或锻打超过对应边界时直接拒绝，不必等到最后一火。

尚未决定出炉的料先占用至少 min 的炉内时段，属于必要条件放松；每次把出炉延后都重新检查全部占用。它允许更广的构造，不代表每个前缀均可补全。候选生成目前是关键事件时刻和代码指定的延迟，不是全部整数时刻的穷举。生成候选失败不能证明原问题无解。

同车不能在压机交换料；不同车可以在旧料取走的时刻送达新料。空驶与负载运输耗时不变。炉内带料换温仍禁止，保温上限、容量和立即回炉规则不变。

`probe` 可对当前部分安排调用完整 CP 模型，固定已选择的工序时间、炉子和车辆；瞬时事件顺序仍由模型补齐。只有 INFEASIBLE 能剪掉对应固定分支，UNKNOWN 不能。建模时间计入总耗时，因此不建议每一步调用。

首日上界不再使用“最新预约时刻之后还剩多久”，因为允许插入更早空隙。它累计已排首日锻打，以及未排工序在乐观最早开始下最多还能贡献的时长，再按压机当天剩余空闲长度截断。保温次目标开启时，首日上界相等不直接剪除。

## 持久化与恢复

运行级 checkpoint 保存队列、最好合法方案、修复链、经验和任务归属。恢复重新核验最好方案，未完成工具调用标记为 UNKNOWN。
算法级 checkpoint 由代码显式保存自己的控制状态；引擎连同状态句柄和候选保存。没有调用 checkpoint 的算法只支持重跑，不虚称能恢复 Python 栈。算法、订单或环境版本不一致时拒绝使用旧算法检查点。
CP-SAT 内部搜索树不支持本项目的持久化恢复；恢复的是任务和已知合法结果。

## 评估

相同订单、车辆和独立审计下，分别记录旧构造、新构造、新提示词、真实模型修改。
总 wall time 包含 API 思考、工具、构造、建模及双重校验；并发任务时间相加不能代替总历时。
指标：首次完整合法时间、完整合法成功率、首日锻打、总代价、失败类型、模型实际请求数、版本差异。部分工序数仅作诊断。
短测不能证明新的开放构造器优于原算法，也不能证明 Memory 已在广泛客户分布上泛化。

## 模型协议修复

主模型默认通过供应商 `output_config.format` 请求严格JSON Schema，避免说明文字、重复JSON和字段名拼写影响执行。它不保证代码逻辑正确。兼容模式仍只接受一份完整、无歧义的JSON，不拼接、猜测或修补执行字段。当前接口依据：[阿里云 Anthropic Messages](https://help.aliyun.com/zh/model-studio/anthropic-api-messages)。

API参数在执行前按实际Python签名检查。`batches`必须传入覆盖当前订单的waves；无参调用立即返回具体错误。新环境使用branch_switches统计从较早状态展开其他分支，不把没有采集的回退次数固定显示为0。
