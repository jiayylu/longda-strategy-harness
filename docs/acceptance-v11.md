- 退役必须提供理由和证据。替代卡必须是启用、同阶段且保留原条件/证据；证据错误或适用规则失效须有独立问题记录。UNKNOWN 不足以退役。原成功证据不能在普通更新中悄悄删除。
- 更新器附带旧卡引用的原始事实；逐条检查阶段、版本、证据、临时别名、字段长度和文字引用。结构化校验不能保证自然语言所有结论都正确，因此仍保留观测性限定与人工复核。

- 这证明保护机制可拦截这类错误，不意味着辅助模型已经能稳定产生有价值的新经验。
